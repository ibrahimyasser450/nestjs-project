## 📖 Overview

Booking System with Kashier, user can payment online with Kashier and send enail for user to payment and send successful email

---

## ✨ Features

- 🤵 SignUp & Login
- 🔐 Authentication & Authorization
- 👤 Complete User CRUD Operations
  - ➕ Create User
  - 📖 Read Users
  - ✏️ Update User
  - 🗑️ Delete User
- 📧 Send Emails
- 💸 Payment Online
- ✅ Request Validation
- 🔒 Password Hashing with bcrypt
- 📱 Responsive Design
- ⚡ Fast Performance

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/ibrahimyasser450/nestjs-project.git
```

Go into the project

```bash
cd nestjs
npm install
```
---

## 🔑 Environment Variables

Create a `.env` file in the backend directory.

```env
PORT=3000
```
---
## ▶️ Running the Project

Backend

```bash
npm run start:dev
```
